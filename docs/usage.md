# 筑稿 · Build Draft 0.15.0

Minecraft **1.20.1** / Fabric Loader **0.19.5** / Java **17+** 的客户端草稿建造工具。只围绕无碰撞自由视角、方块选取、贴面建造、实景 / 虚影、撤销 / 重做、多草稿管理和施工辅助提供操作。

## 自由飞行

- 进入编辑器后，从玩家眼睛位置和朝向开始，鼠标直接转向，屏幕中央准星决定建造落点。编辑器和方块库中隐藏玩家手部及手持物，退出后恢复。
- 按住 WASD 连续飞行。W/S 沿注视方向前后移动，可以向上或向下飞；A/D 横移。空格垂直上升，Shift 垂直下降，Ctrl 三倍加速。
- 默认速度 24 格/秒，Ctrl 加速时为 72 格/秒。斜向移动不会额外加速，松开按键即停，相机位置按游戏帧插值。
- 视角可水平转满一圈，俯仰范围 -90°–90°。相机位置独立于玩家，不进行方块碰撞检测，可穿过地形和草稿；不修改玩家游戏模式，也不把相机移动写回玩家的位置和朝向。
- Home 让视角回到玩家眼睛位置。退出编辑器恢复原版视角和鼠标操作。
- Tab 释放 / 捕获鼠标。释放时飞行与连续建造停止，可点击选材栏；再按 Tab 或点击空白画面恢复飞行，恢复用的点击不会同时建造。
- 窗口失焦会停止飞行和连续建造并释放鼠标。返回窗口后按 Tab 或点击画面继续。
- 仍只显示游戏已加载区块，不额外请求远处区块；自由视角不会让玩家本体跟随移动。

## 建造与选材

- 右键在真实地形或草稿表面添加虚拟方块，左键只删除草稿。按住每约 180 毫秒连续操作，始终重新拾取准星指向的面。
- 瞄准时只显示中央准星，不显示待放置方块、落点框或贴面高亮；右键后才显示加入草稿的方块。贴面落点与自动朝向仍在后台计算。空白处不提供虚拟平面落点，不支持凭空起建。
- 默认自动计算朝向，支持新楼梯朝向、原木轴向和台阶合并等原版放置状态。R 旋转并切到手动属性，Shift + R 恢复自动朝向。中键或 M 吸取草稿 / 真实方块的完整状态并切到手动属性。
- 下方 12 格选材栏独立于玩家真实物品栏。首次进入只读取玩家 9 格中的方块，其余槽位补入常用材料；每个槽位保存自己的方块状态。飞行建造时直接滚轮循环切换全部 12 格，上滚前一格、下滚后一格；首尾相连，不再调整飞速。
- F 或释放鼠标后右键槽位 / 点击“+”打开方块库，支持名称 / ID 搜索、材质 / 形状分类和原版 / 模组来源筛选。选好后返回即恢复自由飞行。
- 保留 V 切换实景 / 虚影。实景显示原材质，虚影使用固定 45% 不透明度；Ctrl + Z / Ctrl + Y 撤销 / 重做。

## 方块库

- 材质与形状同时筛选，不再在两套分类页之间切换。主分类为全部、木材、石材、彩色建材、玻璃、自然、装饰、其他；形状为全部、完整方块、楼梯、台阶、墙 / 围栏、门 / 活板门、其他形状。
- 例如选择“木材 + 楼梯”只看木楼梯，“石材 + 台阶”只看石台阶。来源和搜索继续叠加应用；搜索支持空格分隔的多个关键词，所有关键词都要匹配。
- 同一方块只归入一个主材质类。分类优先使用标签、方块类型和材质声音，注册 ID 作补充；模组木板系列可以帮助识别同一木种的楼梯、台阶等形态。未识别内容保留在“其他”。不依赖中文名称猜测材质。
- 方块按材质、同系列、变体顺序排列。例如橡木原木、去皮原木、木板、楼梯、台阶、围栏和门相邻；玻璃与玻璃板放在一起，彩色系列采用统一色序。
- 顶部常驻“最近使用”，记录最近选用或放置的最多 24 种方块，不重复。最近一栏也遵守当前材质、形状、来源、搜索与特殊开关；选择已有材料会移到最前，Shift 自动跳到下一个槽位不会把未选择的新槽材质挤到最前。
- 特殊方块默认隐藏，包括没有物品的技术方块、结构 / 指令方块、墙上火把、盆栽、含水炼药锅等重复或特殊形态。开启“特殊方块：显示”可查看，水和岩浆仍以桶图标显示。
- 保留 12 格选材栏、数字指定槽、Shift 连续装填和快捷栏滚轮。记住当前世界会话的分类、来源、形状、特殊开关和搜索文字；最近使用与这些筛选不跨游戏重启保存。
- 小窗口将分类条压缩成材质 / 形状循环按钮；极小可用高度会收起最近一栏，为方块和选材栏留出空间。

## 草稿管理

- 普通游戏或编辑器内按 L（可改绑）打开；也可 Tab 释放鼠标后点击右上角“草稿”。页面沿用纸面风格，列表显示名称、方块数量、最近保存时间；可翻页或在列表上滚轮翻页。
- 输入名称后点击“保存为新草稿”或回车，可保存当前内容。名称支持中文，最长 48 字；同名保存不会直接覆盖，需选择已有草稿并使用“更新选中”，再次确认后覆盖。
- “新建空白”开始空白草稿；“载入编辑”恢复所选草稿的方块和原世界坐标，视角移到草稿附近。切换或新建前，若当前非空内容尚无相同坐标和内容的存档，会自动保存为“切换前 时间”，保存失败则中止切换。
- “删除选中”需要再次确认，可取消。只删除该份命名存档；当前正在编辑的内容保留，因此之后仍可重新保存。
- 草稿按当前世界和维度分别保存在 `build-draft/autosaves/<世界与维度摘要>/drafts/<名称>.json`；重启游戏后可继续查看。命名草稿独立于后台 `session.json`，编辑后的改动需手动更新该份存档；后台仍每约 10 秒保存当前工作内容。
- 损坏文件仍显示在列表中并标注不可读，不阻挡其他草稿；缺少世界原点的旧文件不能直接载入。原有旧版命名蓝图、recovery.json 不自动迁移。
- 载入不会修改真实世界，也不会移动玩家或额外加载区块；远离玩家的未加载区块仍不可显示。切换后撤销 / 重做从新草稿开始。

## 施工投影与材料统计

- 草稿页选中已保存草稿，点击“投影：关闭 / 虚影 / 实景”循环切换；同时只显示一份。返回普通游戏即可看到原坐标的投影，没有碰撞；“关闭施工投影”随时关闭。选择与显示模式按世界 / 维度保存到 `projection.json`，重进世界自动恢复。
- 已正确建好的投影自动隐藏；错方块或不可填补的位置用红色轮廓标出。正常的邻居连接、楼梯连接形状和开关 / 通电变化不会误判为未完成；朝向、原木轴向、台阶半部仍要求正确。编辑时只显示当前设计，离开编辑后才显示独立的已保存施工投影。
- 单人世界：开启已保存草稿的投影，返回普通游戏，主手拿对应材料，按住左 Alt 并右键一次，在一次服务端任务中填充整份草稿里所有使用该物品的待建位置。不同朝向仍归为同种材料；放置采用草稿状态，无需瞄准、走近或等待逐格施工，远处目标所在区块会按需加载。
- 生存模式从主物品栏、快捷栏及副手扣除实际材料，不限手上这一组；够多少填多少，缺料提示所需补充数量，补料后再次组合键继续。创造模式不扣料。已完成位置不重复扣料；不同材质保持原样。双台阶 / 叠放方块按缺少的物品数补齐，门 / 床完整成组放置且只计一个物品。
- 一个组合输入只执行一次，持续长按不会重复填充；松开右键后可再次触发。辅助键和游戏使用键沿用改绑。HUD 显示已填格数、消耗、缺料与跳过结构数；没有常驻施工队列或再次点击停止功能。
- 服务端执行保留世界高度、边界、修改权限和实体占位检查；真实方块冲突、不完整多格结构会跳过，不覆盖已有建筑。整批写入后通知正常邻居更新，重力、支撑与红石规则仍会生效，依赖支撑的材料建议在地基 / 支撑建好后填充。复杂草稿的区块加载与整批写入可能短暂卡顿。
- 当前版本仅在单人集成服务端提供整份真实填充，多人连接只显示“需要服务端支持”提示，不能靠客户端让远程服务器一次放完整份草稿。水、岩浆、含水状态、无对应物品及部分特殊 / 模组结构需手工处理；不生成免费水，不保存或重放方块实体 NBT，带 BlockStateTag / BlockEntityTag 的材料不参与扣料。
- 选中草稿点击“材料统计”，按实际物品合并不同朝向 / 状态，显示总需、完成、待放、背包、缺口。双层台阶按两个材料，门 / 床按一个物品，雪层 / 蜡烛等按叠放数量；含水状态另列手工水桶需求。主物品栏及副手都计入库存，未加载区块按未完成保守统计并提示。统计每半秒刷新，不移动玩家或额外加载区块。
- 更新正在投影的存档会同步刷新投影；删除正在投影的存档会先关闭投影。仅修改设计不会自动覆盖已保存的施工版本。

## 设计撤销与全部删除

- 编辑器右侧新增“撤销上一步”“全部删除”。按 Tab 释放鼠标后点击，撤销与 Ctrl+Z 相同。
- 全部删除需要再次点击“确认全部删除”，可点击“取消删除”或按 Esc 取消。清空作为一次操作加入撤销历史，因此可一次恢复全部设计；只影响当前设计，不删除命名草稿存档或真实世界方块。

| --- | --- |
| B（可改绑） | 打开 / 关闭编辑器；已有实例若改成 End，会沿用 End |

| 滚轮 | 飞行时循环选择 12 格建材；释放鼠标时在选材栏上切换 |
| Tab | 切换自由飞行与鼠标选材 |
| 左键 / 右键 | 删除 / 添加草稿；释放鼠标时用于界面操作 |
| 中键 / M（可改绑） | 吸取准星所指方块及其属性 |
| F（可改绑） | 方块库 |
| L（可改绑） | 普通游戏 / 编辑器：草稿管理、投影与材料统计 |
| 1–9、0、-、= | 选择第 1–12 个建材槽 |
| R（可改绑） | 画笔旋转 90°；Shift + 对应旋转键恢复自动朝向 |
| V（可改绑） | 实景 / 虚影 |
| Home（可改绑） | 视角返回玩家位置 |

释放鼠标后，可在选材栏上滚轮切换槽位。方块库支持指向方块按槽位数字直接装入，Shift + 点击连续装填；搜索输入聚焦时可正常输入文字。

普通游戏中可用呼出、草稿管理与施工辅助；其余编辑快捷键只在编辑器中执行。按键注册保留呼出、实虚、旋转、吸管、方块库、返回玩家、草稿管理、施工辅助八项，可在 Minecraft 的按键设置里修改。固定的 WASD、空格、Shift、Ctrl、Tab 和数字栏操作在编辑器中处理。

## 精简内容与数据

- 旧版蓝图库由新的草稿管理页替代；材料统计与施工投影已重新加入；仍移除属性编辑页、原点移动、辅助网格和侧栏 / 顶部工具菜单。
- 高度建造、锁平面、矩形、拉伸、移动网格继续移除；N、P/F12 及旧工具键不再由筑稿注册。
- 退出编辑器后，只显示明确开启的已保存施工投影；设计中的未保存修改不会混入施工投影。重新打开编辑器可继续当前世界的草稿。
- 自动保存和恢复在后台进行。每 10 秒、离开编辑器、离开世界时，将草稿和世界原点一起原子保存到当前运行目录的 `build-draft/autosaves/<世界与维度摘要>/session.json`。
- 下次进入同一世界 / 维度会恢复新格式的会话，保留原世界坐标。旧版 `recovery.json` 与命名蓝图文件不删除、不覆盖，也不会在缺少世界原点的情况下自动移到玩家身边。
- 损坏或缺少模组方块的恢复文件会保留并提示；该次会话停止写入自动保存，避免覆盖原文件。
- 每份草稿最多 32,768 格，最多 128 步历史。撤销历史不跨游戏重启；方块栏与实虚状态仅在当前世界会话保留。

## 安装与构建

游戏实例 `mods` 中需要 Fabric API 0.92.2+1.20.1 或兼容的更新版，以及 `build-draft-0.15.0.jar`。同一实例只安装一个筑稿版本，不安装 `-sources.jar`。设计、草稿管理和投影属于客户端功能；整份真实填充当前支持单人集成服务端，尚未提供多人服务端组件。

```powershell
# JDK 17 或 21；首次需要联网下载依赖
.\build.ps1
.\build.ps1 -Tasks test
```

升级时先退出游戏，将实例 mods 中旧的筑稿 JAR 替换为 `build-draft-0.15.0.jar`，再重启；0.13.0 没有施工填补功能，0.14.x 也不是整份瞬间填充，仅下载新版不会让正在运行的旧版生效。

产物：`build/libs/build-draft-0.15.0.jar`。Windows 脚本通过临时目录链接处理 Gradle 的中文路径问题，不移动源码。

设计编辑只修改虚拟草稿；普通游戏中的辅助填补会真实放置方块，并按游戏模式消耗材料。门、床等多格结构仍需逐格设计，不保存方块实体 NBT，也未完整重放邻居更新。相机无碰撞不等于修改玩家为旁观模式；世界继续运行。实际测试范围见 `VALIDATION.md`。
